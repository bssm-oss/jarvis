Live2D assets used by the Jarvis voice activation overlay.

- Model: Nijiiro Mao / 니지이로 마오 (PRO version), downloaded from Live2D's
  official sample data page as `mao_pro/mao_pro_ko.zip`.
- Bundled runtime files are the contents of the ZIP's `runtime` folder:
  `mao_pro.model3.json`, `mao_pro.moc3`, expressions, motions, physics, pose,
  display info, and texture assets.
- Runtime: Cubism 4 Web runtime file `live2dcubismcore.min.js`, loaded locally
  from `web/public/vendor/live2dcubismcore.min.js` for offline desktop operation.
- License/use terms: the included `mao/ReadMe.txt` states that use requires
  agreement to Live2D's free material license and sample data terms. Keep those
  terms attached when redistributing this prototype.

These files are bundled only for the local Jarvis voice overlay prototype.
